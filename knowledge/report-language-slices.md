# 评语语言切片库（RAG 语料）

> 来源：行业测评报告撰写规范（内部整理，2026-08-22）。
> 用途：注入评分工作流 prompt，约束评语文本的风格与写法（词典锚点管"打得准"，本切片管"写得专业"）。
> 切片原则：每块独立成义、可单独检索注入；元数据头标注适用场景。

---

## 切片 R1：评语核心规则（正反对照）【适用：dimensions 评述、highlights/improvements 文本】

| 规则 | 正面样例 | 反面样例（禁止） |
|---|---|---|
| 前后一致不自相矛盾，可按构面分别写 | "沟通有很强的主动性，但沟通的策略性不足" | 前写"激励团队达成目标能力强"后写"调动员工积极性的措施有限" |
| 与岗位典型场景相关，落到具体情境/行为 | "缺乏培养下级的意识""不能调动团队成员的积极性" | 通篇"做事认真负责、责任心强、积极进取"；"管理能力需要提升" |
| 与高绩效行为相关，而非贴性格标签 | "急于达成目标，而忽略某些重要细节" | "情绪急躁" |
| **用行为差异而非程度副词体现高低** | "推进工作不遗余力" / "按部就班完成上级交代工作" | "推进执行能力强""推进执行能力较强" |
| 致命性不足慎写、委婉表达 | "考虑问题不够周全，有时对细节问题会有所忽视" | "风险意识差" |
| 句式丰富多样 | "责任心较强……具有良好的沟通能力……管理上有思考" | "责任心较强……沟通能力较强……管理能力较强……" |
| 用词准确简炼，无术语/生僻词/口语 | —— | "人际敏感性强""内源性成就动机""对待员工像对待自己的孩子" |
| 分数与评述一致：分高优势多于不足；分低不足多于优势且需有说服力；中间档须说明保留了什么 | 排名靠前者优势突出 | 优秀者写得无可挑剔 / 靠后者写得一无是处 |
| 每条评述只描述一个胜任力，既有水平又有行为描述 | —— | 混写多条 |

## 切片 R2：总评（profile）写法【适用：报告 profile 字段】

1. 先在脑海中勾画候选人整体形象，再分维度描述——写完后形象应是鲜明的；
2. 总评不照搬分维度的优缺点原文，换词语、换角度综合；
3. 剖析最高分与最低分维度要具体点名；
4. 不只是就胜任力论胜任力——点出能力差异的可能成因（历练不足 / 客观条件限制 / 自我认知不足 / 性格使然）。

## 切片 R3：培养建议写法【适用：improve 字段】

建议须具体、合理、有针对性、可落地，从七个角度取材（不同人建议须有差异）：
① 历练机会（复杂工作任务、轮岗）② 资源支持（上级协调、化解分歧）③ 培训 ④ 物质/精神鼓励 ⑤ 平台（沟通与展示平台）⑥ 上级传授方法经验与反馈 ⑦ 上级的引导提醒。

写优秀的人的不足时，可限制情境或附解决路径："面对……的情景可能会有挑战"。

## 切片 R4：区分性原则【适用：所有评述文本】

不同候选人的评述要有区分性，不能千人一面；优缺点相对均衡、略有差异。若能力表述难以精确对应词典，可做"情景化的行为提炼"——给行为加具体限定词以作区分。
