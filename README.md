# TalentOS · AI 原生人才培养平台（原型）

以"AI 产品经理"岗位为样本：**岗位能力模型为地基，陪练官对话为体验核心，证据链评价为出口**。

## 产品形态

自闭环培训产品，**培训包为基本单元**：前测（陪练官对话）→ 必修/选修课程 + 沙盘演练 → AI 导师答疑 → 后测成长报告。
- **移动端候选人 H5**（m.html，文档表述为 APP）：学生全流程体验，真 AI 对话
- **教师端管理后台**（index.html）：数据看板、项目管理、AI 生成课程包→教师定稿、项目详情
- 同一部署两个入口、共享数据层；教师以"必修课配置人"在场，企业以"真题出处"在场

## 快速开始

```bash
# 前端静态站（端口 8090）
python -m http.server 8090
# 后端（端口 3090；设 TOS_LLM_KEY 即真 AI 模式，不设为虚拟模式）
TOS_LLM_KEY=<智谱key> node server/index.js
# 访问
#   移动端  http://localhost:8090/m.html?fresh#/login
#   教师端  http://localhost:8090/index.html
# 演示约定：验证码 123456；白名单 138****0001/0002/0003
```

## 结构

```
index.html / m.html        PC 教师端 / 移动候选人端入口
assets/css|js|vendor       设计 token（DESIGN.md 规范）、应用代码、ECharts 本地依赖
server/index.js            零依赖 Node 后端：陪练官 Agent + 评分工作流（3090）
knowledge/                 能力词典语料（胜任力/知识/技能三本 + 编码体系 + 报告语言切片）
docs/                      产品设计文档 + 各模块验收清单
```

### M1 功能清单

1. **双端结构**：教师端（`#/admin`）与学生端同一部署、共享数据层，顶导航一键切换
2. **数据看板**：统计块、待办中心（终审队列 / AI 上抛干预信号分级 / 内容更新建议）、班级能力热力图（对标岗位标准线）、动态流
3. **项目管理**：项目卡片列表 + 四步新建向导（岗位模板→**AI 生成课程包草案→教师编辑定稿**→学员导入→前测发布）
4. **项目详情**：学员情况（五域雷达/进度/风险标记）、课程配置（必修/选修/沙盘）、成果与评价（AI 预批改 + 教师终审队列）

### M2 功能清单

手机号+验证码登录（白名单真实逻辑，非白名单直达无权限页）；演示分支弹窗（仅白名单触发，外挂装置+红字声明，不碰真实权限逻辑）；开通申请记录（同号再次进入显示上次记录）+ 运营中台说明弹窗；iPhone14 标准框（390×844/灵动岛）等比缩放零滚动条；Hero 蓝渐变擦除动效；账号按手机号分仓隔离。

### M3 功能清单

**陪练官对话**：指定开场白 + 4 话题框架（映射词典维度 ID）+ 意图识别五分支（问评分挡话术/疲惫收尾/拒答换法/短答追问/正常）+ 单话题追问上限 1 次 + 外挂总轮次断路器（3 轮收尾，不改 Agent 内部逻辑）。
**评分工作流**（独立于主 Agent，最小知识原则防套话）：词典锚点 + 行业报告语言切片双锚定，软/硬技能分组，四级区间分，评述按报告质检规范（行为差异非程度副词），证据逐字摘录，真 AI 失败自动降级。
**成长报告**：软技能雷达图（悬停显分）+ 硬技能条 + 待定级卡（钩住培训包）+ 横向百分位条（标准分+正态 CDF，演示常模 N(0.40,0.23)，无样本特判 0%，30/70 三档等级）+ 导读区。
**交互与工程**：微信式输入栏（键盘/按住说话双模式，Web Speech 语音识别）、对话只读回看态、报告一次生成即定稿（双层缓存）、CORS、API key 仅存环境变量、资源版本号防缓存。
