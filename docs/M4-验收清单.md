# M4 · 培训包与课程学习 · 功能规格与验收清单

> 2026-08-22 用户确认范围：虚拟入职叙事 + 要我学/我要学 + 视频课占位 + 课后练习纠偏（1 门真做）+ 规则组装不走大模型。教师前置（只定内容与强制项，不定顺序）。

## 功能点

1. **入职开场页**（报告 CTA 打通）：虚拟入职叙事——欢迎加入虚构公司"启明科技"，导师形象（内联 SVG），入职学习计划说明，"领取我的入职培训包"按钮
2. **培训包生成（规则组装，纯工程）**：读本手机号的首聊报告 → 选修排序 = 课程权重 × 维度差距分；必修 = 老师强制标志；生成结果按手机号分仓存储
3. **我的培训包首页**：总进度环 + "要我学"（老师指定必修，2 门）+ "我要学"（定制推荐选修，3 门，标注"根据你的初聊画像推荐"）+ 岗位任务卡（沙盘占位，"即将开放"）
4. **课程卡**：微课图标 + 课程名 + **能力目标句**（线框图写法："实现对XX的有效管控"）+ 关联能力标签 + 进度条
5. **课程详情页**：课程能力目标句 + 微课视频占位（16:9 播放器样式）+ 章节列表（可勾选完成，回填进度）+ 课后练习
6. **课后练习（1 门真做）**：《大模型基础与边界》3 道单选题 + 逐题纠偏解析 + 答对勾选章节 + 完成提示解锁语（"岗位任务即将开放"）
7. 其余课程章节可浏览勾选，练习区显示"练习建设中"

## 验收标准

| # | 验收点 | 预期 |
|---|---|---|
| 1 | 报告页点"领取定制培训包" | 进入入职开场页（叙事+导师形象+按钮），不再是 toast |
| 2 | 领取培训包 | 生成并进入培训包首页；进度环 0%；含要我学 2 门/我要学 3 门/岗位任务占位 |
| 3 | 选修推荐有据 | 我要学课程按报告差距排序，卡片带"根据你的初聊画像推荐"标注 |
| 4 | 课程详情 | 视频占位（16:9 播放器样式）+ 章节列表 + 能力目标句 |
| 5 | 课后练习 | 3 道选择题，答错有纠偏解析，答对过关；完成后进度回填、出现解锁语 |
| 6 | 进度 | 章节勾选/练习完成回填课程进度与总进度环 |
| 7 | 账号隔离 | 换手机号登录，培训包各自独立（分仓存储） |
| 8 | 回归 | 首聊/报告/登录流程不受影响 |
