# TalentOS 岗位架构与标识符编码体系

> 参照行业岗位内容框架最佳实践（唯一标识码体系）设计，2026-08-22 用户定规则 + ZCode 扩展提议（FPM 职能层前缀）。

## 一、标识符编码规则

| 类别 | 前缀 | 格式 | 示例 | 说明 |
|---|---|---|---|---|
| 事项类（胜任力） | `CMO` | CMO-数字-名称 | `CMO-01-沟通表达` | 全岗位共享的胜任力词典，共 12 条（CMO-01 ~ CMO-12） |
| 知识技能·通用层 | `GEN` | GEN-名称 | `GEN-AI技术知识` | 全岗位通用（AI 产品/运营/研发皆需） |
| 知识技能·职能层 | `FPM` | FPM-名称 | `FPM-产品方法知识` | **ZCode 扩展提议**：F=Function 职能层；PM=产品职能。未来运营职群为 FOP、研发为 FRD |
| 知识技能·岗位层 | `GPM` | GPM-名称 | `GPM-评测集设计技能` | G+职群代码（用户规则：岗位模型有 PM 则前缀 GPM）。岗位层条目须有对应岗位模型支撑 |

**子级标识约定**（数据录入用）：
- 知识点：父编码.K序号 → `GEN-AI技术知识.K07`（该域第 7 个知识点）
- 任务场景：父编码.T序号 → `GPM-评测集设计技能.T1`
- 胜任力关键行为：CMO-序号.L级.B序号 → `CMO-01.L2.B3`（沟通表达 L2 级第 3 条行为）
- 岗位模型：职群代码-序号 → `PM-01`（AI 产品经理）

## 二、岗位架构图（组织岗位地图·学生版简化）

```
组织岗位地图
│
├── 职群 OP · 运营职群        （规划中，未建 — 架构留位）
├── 职群 RD · 研发职群        （规划中，未建 — 架构留位）
│
└── 职群 PM · 产品经理职群 ✅ 本期建立
      ├── PM-01  AI 产品经理            ◀ 本项目 demo 主线岗位
      ├── PM-02  数据产品经理
      ├── PM-03  B 端产品经理（企业服务）
      ├── PM-04  C 端产品经理
      ├── PM-05  增长产品经理
      ├── PM-06  策略产品经理
      ├── PM-07  平台产品经理
      ├── PM-08  商业化产品经理
      ├── PM-09  供应链产品经理
      └── PM-10  财务数智化产品经理

职级维度（行业职级体系）：学生培养统一对标"个体贡献者·入门档"，
  职级轴本期不展开（架构留位）——行业职级体系反映 leadership
  pipeline，对高校场景降维为"毕业达标线"一个档。
```

**岗位模型组装公式**（行业岗位画像逻辑）：

```
岗位模型(PM-01 AI产品经理) = GEN 全部 6 项
                          + FPM 3 项
                          + GPM 3 项（评测集设计/人机分工设计/AI产品评测知识）
                          + CMO 挑选 8-10 条
                          + 每项目标等级(L1-L4)与 importance(高/中/低)
```
